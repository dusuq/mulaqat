# mulaqat.config.md template

Copy this into `mulaqat.config.md` in your working folder and fill it in. Mulaqat reads it at the start of each session.

```markdown
# Mulaqat config

## Me

- Name:
- LinkedIn profile URL:
- Time zone: (e.g. Asia/Karachi)
- Account size: (connections, approx.)
- Language for outreach: English

## Booking

- Booking link: (Cal.com / Calendly) or free slots:
- Meeting length: 30 min
- Platform: Google Meet

## Targets

- Countries:
- Industries:
- Priority services this month:

## Services

### <Service name>

- Outcome in one line:
- Real results: (1–2, with numbers)
- Price band / timeline: (optional)
- Qualifying questions:

## Tracker

- File: mulaqat-pipeline.csv
```
