# LinkedIn content playbook

Write for buyers, not developers. One idea per piece. Real numbers only.

## Weekly calendar (3–4 posts)

Rotate across the user's priority services. Mix these formats:

| Format       | What it is                                           | Example hook                                                                           |
| ------------ | ---------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Problem post | A pain the buyer recognises + how it gets solved     | "Your WhatsApp is open 24/7. Your team isn't."                                         |
| Build post   | Something the user actually built, behind the scenes | "We replaced 4 spreadsheets with one dashboard for a dairy farm. Here's what changed." |
| Result post  | A real outcome with numbers                          | "First-reply time: 3 hours → 40 seconds."                                              |
| Lesson post  | A short opinion or lesson from client work           | "Most small businesses don't need an ERP. They need these 3 reports."                  |
| Carousel     | 5–8 slides, one idea per slide                       | "7 signs your POS is costing you money"                                                |

Give each post a suggested day and time (weekday mornings in the target audience's time zone usually work; check the user's own analytics once they have some).

## Post rules

- **First line is the hook** and must stand alone before "…see more".
- Short paragraphs, 1–2 lines each. White space.
- 120–250 words.
- End with one clear CTA: comment a keyword, send a DM, or the booking link.
- Up to 3 relevant hashtags at the end.
- Suggest a visual (screenshot, before/after, simple diagram). Offer to make it if a design tool is connected.

## Carousel outline

Slide 1: the promise (hook). Slides 2–6: one point each, ≤25 words. Slide 7: summary. Slide 8: CTA.

## Articles (LinkedIn articles / newsletter)

700–1,200 words. Start with 3 title options, then:

1. Hook intro — a scene or a number (≤80 words)
2. The problem and what it costs the reader
3. The approach — steps or a simple framework
4. A real example (or `[ADD REAL RESULT]`)
5. Common mistakes
6. CTA — book a call, with the link

## Publishing

Everything is a draft until the user approves. Then either the user posts it, or publish via the official LinkedIn API to their personal profile. There is no scheduling API, so remind the user at the chosen time or queue it in their own scheduler.
